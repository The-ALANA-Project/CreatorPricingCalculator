
  # Creator Pricing Calculator

  This is a code bundle for the **Creator Pricing Calculator**. 

  A free pricing calculator for creators and creative freelancers that converts your monthly or annual expenses into a baseline rate, so you can charge fairly and confidently for your work.
  
  The original project is available at https://www.figma.com/design/D9MDMvOp2rZ5AKj0MWQIbs/Creator-Pricing-Calculator.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
